1. 실행 방법

1.GitHub 저장소를 다운로드하거나 클론합니다.
2.프로젝트 폴더에서 index.html 파일을 실행합니다.

2.주요 기능

반응형 웹 디자인 : PC와 모바일 화면 크기에 맞춰 레이아웃 변경
가이드 탭 : 탭 클릭 시 선택한 카드를 활성화하고 배치 변경
TOP 버튼 : 스크롤 시 버튼이 나타나고 클릭하면 페이지 상단으로 이동

3.핵심코드
(media.css)
@media screen and (max-width: 767px) {
    .post {
        flex-direction: column;
    }
}
이유: 화면을 줄여 보는 모바일 화면에서 화면을 세로로 배치해 좁은 화면에서도 글들을 보기 쉽게 만들 수 있었기 때문에
모바일 환경에 맞춰서 변하는 이 코드를 선택했습니다.
